# Security / Sicherheit

Do not publish passwords, device profiles, logs or favourite lists in public issues. Report only a short, non-sensitive description and ask the maintainer for a private reporting channel before sending technical details. No dedicated private reporting address is currently published.

Keine Passwörter, Geräteprofile, Favoritenlisten oder ungeschwärzten Protokolle veröffentlichen. Im öffentlichen Issue nur eine kurze Beschreibung ohne sensible Details nennen und für weitere Angaben zunächst einen privaten Kontaktweg mit dem Maintainer vereinbaren.

The beta is intended for trusted local Windows use and your own local Kodi devices. Do not expose its listener or your Pi's SSH/Kodi ports to the internet. Version 0.1.0-beta is the only current test version; there is no guaranteed support period or automatic updater.
